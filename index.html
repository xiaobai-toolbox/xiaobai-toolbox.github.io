页码从 1 开始;PDF 会插入全部页,图片会作为一整页插入(固定 A4、按比例缩放居中、四周留白)。

PDF 转图片

把每一页渲染导出为 PNG / JPG 图片

每页渲染成一张图片。多页会打包成 ZIP;单页直接下载图片。JPG 会铺白底,避免透明区域发黑。

PDF 转 Word

导出 .docx,用 Word / WPS 直接打开编辑

识别段落、字号、粗体、居中和缩进,图片按原位置插入,每页 PDF 对应 Word 里的一页。表格和多栏排版会尽量对齐,但可能需要手动调整。

文本转 HTML

把文本文件或直接输入的文字导出为独立网页

自动识别 UTF-8 / GBK 编码;「自动识别」下 .md 文件或内容含 Markdown 语法的文本按 Markdown 渲染,其他按段落排版。Markdown 模式会去掉残留的 * 号,代码块不显示语言标记。段落排版:按「一、」「（一）」「1.」「第X条」等编号自动分级标题,适合协议、政策;原样保留:适合日志、代码;Markdown:渲染标题、列表、表格等。多个文件会打包成 ZIP。直接输入时按 Tab 键可插入缩进。
